# 📊 Mobile Sales Dashboard | Power BI Project

## 📌 Project Overview
This project is an interactive **Mobile Sales Analysis Dashboard** built using **Power BI**. The dashboard provides detailed insights into mobile sales performance across multiple dimensions such as brands, cities, payment methods, months, and yearly trends.

The goal of this project is to transform raw sales data into meaningful business insights through visualization and KPI analysis.

---

## 🚀 Features

- Interactive Power BI Dashboard
- KPI Monitoring
- Brand-wise Sales Analysis
- City-wise Sales Performance
- Monthly & Quarterly Trends
- Payment Method Analysis
- MTD (Month-To-Date) Reporting
- Same Period Last Year Comparison
- Dynamic Filters & Slicers
- Data Visualization & Reporting
